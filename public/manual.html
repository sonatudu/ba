Ba user manual

Last updated: 18 September 2026 · Private room for two: Ba and Ma

This guide lists every main screen, button, and gesture. Shared data is encrypted on the device. There are no ads and no public profiles.

Getting in

The welcome screen is the only door. You need the shared room code.

Ba / Ma
Pick who you are. This is remembered on the phone. Ba and Ma see the same room with different labels.
Code
Numeric room code. Enter it and tap Open.
First-time questions
The first open on a new install asks two short setup answers. After that, only the code is needed on that device.
Open
Signs you into the shared room.
User manual
Opens this page.

Home

Home is the hub. The phone Back button returns here from other screens (and closes nested Periods/Memories editors first).

Days together
Shown under the Ba wordmark once a relationship start date is set in Settings.
Daily quote
A quiet line that changes with the calendar day. Not a button.
Poke (large tile with the time)
Sends a poke. Your phone vibrates. The partner’s phone vibrates only — no banner, no sound. The time on the tile is the last poke.
Chat, Routine, Daily, Where, To Do, Overview, Memories, Periods, Family
Open that section. A dot or highlight can mean unread chat or new activity.
Chat — long press
Offers Clear chat for the whole thread (with a confirm).
Settings (gear, bottom)
Opens Settings.

Chat

Opens on the latest message. The keyboard stays open after send on the phone.

Message field
Type here. On a computer, Enter sends and Shift+Enter makes a new line. On the phone, Enter is a new line; use Send.
Send (paper-plane)
Sends the message without dismissing the keyboard.
↓ jump
Appears if you scroll up. Jumps to the newest messages.
Long-press a message
Copy, Edit (your messages), Delete.
Reply bar
If you are replying, the quoted preview shows above the field. The × cancels the reply.
Calls
Incoming call overlay: Accept or End. Chat notifications can show a banner; poke never does.

Routine

Ba / Ma
Switch whose timetable you are looking at. One person’s schedule at a time.
Classes
Week timetable for the selected person.
Mess
Shown with Ma’s routine.
Courses
Shown with Ba’s routine.

Daily

Shared habits with a Ba column and a Ma column. Each task can belong to Both, Ba, or Ma. Percentages and the graph use that person’s own task count (done ÷ their tasks).

Ba n/m and Ma n/m
Completed over that person’s total for the selected day.
Day strip
Jump to a day this month. Sundays are marked in red. Swipe the strip sideways.
Calendar icon
Jump to another date (not in the future).
Completion graph
Ranges: Today, Week, Month, Year, Overall. Two lines: Ba and Ma.
Ba / Ma ticks on a row
Mark that person done for that task. Empty dashed circles mean the task is not theirs.
Edit
Opens add/rename/reorder. Time-of-day label cycles Morning → Afternoon → Evening → Night. The person label cycles Both → Ba → Ma. Drag the handle to reorder inside a slot. Long-press a row to delete.
Add a daily task
Type the name, pick time of day and Both/Ba/Ma. Enter adds while staying in Edit. Done saves the field, any renamed tasks, and leaves Edit. There is no separate tick next to the add field.

Where

Map of the two of you. Location is optional (Settings → Share location). Each person has one pin. If the same person is signed in on more than one phone, the pin is the latest active device (last used or last location sent), not merely the last login.

Ba / Ma locate buttons
Fly the map to that person’s pin and follow it.
Compass
Reset north.
N
Natural / satellite-style map.
P
Political / street map.
Full screen
Expand or exit the map.
Pinch / drag
Zoom and pan. Tiles stay visible at high zoom on both N and P.

Us / Ba / Ma

Priority dots

Overview

Day notes, good and bad, for one date.

Calendar icon
Jump to another day. Swipe the month if the picker is open.
Add
Opens Good / Bad and a text field. Save stores the note.
Tap a note
Open to read or edit.

Delete.

Memories

Coming up
Yearly or dated memories in the next 45 days.
All
Grouped by year (and Yearly). Tap a card to edit title, story, date, and “Repeat yearly”.
Add (when composing)
Date, yearly toggle, title, story, Save.
Long-press
Delete (kept built-in dates stay marked Kept).

Periods

Ba-only tracker. Summary, calendar, Record period, Meprate, and Gap.

Summary

Period start, cycle day, fertile window, next period, days between periods, period length — from logged days, with Settings as fallback.

Calendar

Swipe left / right
Change month (neighbour month peeks while you drag).
A day cell
Sets the date for Record period. Colours: period, predicted period, fertile, today.

Record period

Logged day by day, like Meprate — not a single start/end range.

Date
The day you are recording.
Status
Still on = still bleeding that day. Ended = last day of this period.
Menstrual flow
Light / Medium / Heavy.
Symptoms
Tick any that apply. Pencil: Add, Remove, Done for the symptom list.
Notes
Optional.
Save / Update
Writes that day. History is month buttons; open a month for daily rows until Ended, then a month summary. Long-press: Edit, Last day (if still on), Delete.

Meprate

Date
The day of this log.
Status
Still on / Ended (end of the course for that month).
Taken / Not taken
If not taken, a reason is required.
Save
Daily history until Ended, then a month summary. Long-press: Edit or Delete.

Gap

Days from Meprate end to the next period start (diary gap(m)).

Period settings (gear)

Days between periods
Fallback cycle length when there are few logs.
Period length
Fallback bleed length.

Family

Two-sided family tree. Edit name, nick, and birth on a card; it saves as you type. Locked cards cannot be deleted. Long-press an unlocked card to remove it. Scroll the chart; lines redraw with the layout.

Settings

Sun / moon
Day theme or night theme.
Relationship start date
Sets the home “days together” count. Calendar picker.
Share location
On: Where can show your pin. Off: location is not shared. Optional.
Notifications
On: chat and calls can show a banner. Poke still only vibrates.

Privacy policy
How data is stored and deleted.
Log out
Leaves the room on this device. Data in the room stays for the other person until they delete the account.
Delete account
Opens a Room code field. Enter the same code used to open Ba, then tap Delete. Wrong codes are rejected. Cancel closes the form without deleting. This closes the shared room.

Gestures that show up in several places

  • Phone Back — close the current screen or nested editor; from Home, leave the app. The app stays above the phone’s home / recent / back bar and below the status bar, like other apps.
  • Long-press — delete / edit menus on tasks, period history, memories, family cards, chat messages.
  • In-app calendar — tap the date control; change month with ‹ › or by swiping; tap a day.
  • Keep / Delete — confirm before something is removed.
